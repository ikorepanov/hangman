# Hangman

Учебный проект консольной игры "Виселица" на Python. Игра демонстрирует работу с пользовательским вводом, ASCII-графикой и терминальными ANSI-последовательностями. Проект показывает применение базовых принципов структурирования кода.

---

## Цель проекта

Отработка навыков реализации цельных приложений на Python и закрепление практики работы с консольным интерфейсом, обработкой ошибок и логикой игровых циклов.

---

## Описание игры

Игра "Виселица" предлагает пользователю отгадать случайное слово. Игровой процесс включает:

- ввод буквы игроком;
- проверку корректности ввода;
- отображение текущего состояния слова;
- визуализацию прогресса виселицы через ASCII-графику;
- подсчет ошибок и отображение уже использованных букв;
- завершение игры при победе или поражении.

После окончания игры пользователь может начать новый раунд или выйти из приложения.

---

## Используемые технологии

- Python 3.9+
- ANSI escape sequences для управления курсором и очистки экрана

---

## Установка

Клонируйте репозиторий:
```sh
git clone https://github.com/ikorepanov/hangman.git
```

Перейдите в папку hangman:
```sh
cd hangman
```

Разверните виртуальное окружение:
```sh
python -m venv .venv
```

Активируйте виртуальное окружение:
* Linux и macOS
  ```sh
  source .venv/bin/activate
  ```
* Windows
  ```sh
  .venv\Scripts\activate
  ```

Обновите `pip`:
```sh
python -m pip install --upgrade pip
```

Установите проект:
```sh
pip install .
```

---

## Запуск игры

Запустите приложение:
```sh
python -m hangman.main
```

В дальнейшем - следуйте указаниям на экране.

---

## Конфигурация

Список слов для отгадывания хранится в ../data/dictionary.txt и, при необходимости, может быть заменён на файл с аналогичной структурой данных.
